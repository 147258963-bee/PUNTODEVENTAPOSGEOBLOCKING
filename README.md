# 🛰️ GEO BLOCKING - Enterprise Cloud ERP v11

¡Bienvenido al sistema de gestión oficial de **GEO BLOCKING**! Este es un ERP (Enterprise Resource Planning) de alto nivel diseñado para funcionar totalmente en la nube, optimizado para el control de inventarios, ventas y reportes financieros en tiempo real.

## 🚀 Características Principales

* **Sincronización Cloud:** Conectado con Google Firebase para actualización instantánea entre dispositivos.
* **Terminal POS Pro:** Interfaz de punto de venta optimizada para escáneres de códigos de barras.
* **Gestión de Inventario:** Control total de SKU, costos, precios de venta y alertas de stock bajo.
* **Módulo Financiero:** Cálculo automático de ingresos brutos, utilidades netas e impuestos (IVA 19%).
* **Seguridad Multiusuario:** Acceso restringido para 15 perfiles autorizados con tokens de seguridad.
* **Dashboard Ejecutivo:** Gráficos de rendimiento semanal para la toma de decisiones.

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3:** Interfaz moderna con diseño *Dark Mode* empresarial.
* **JavaScript (ES6+):** Lógica de negocio y procesamiento de datos.
* **Firebase Firestore:** Base de Datos NoSQL en tiempo real.
* **Chart.js:** Visualización de analíticas de ventas.
* **GitHub Pages:** Hosting de la plataforma.

## 📦 Instalación y Configuración

1. **Configuración de DB:**
   - Crear un proyecto en [Firebase Console](https://console.firebase.google.com/).
   - Obtener las credenciales `firebaseConfig`.
   - Pegar las credenciales en la sección correspondiente del archivo `index.html`.

2. **Despliegue:**
   - Subir los archivos a este repositorio.
   - Activar **GitHub Pages** desde `Settings > Pages`.

## 🔒 Acceso de Seguridad

El sistema cuenta con 15 usuarios pre-configurados (`user1` al `user15`).
